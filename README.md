# DDoS Attack Detection Using Machine Learning

Machine learning project for detecting **Distributed Denial-of-Service (DDoS) attacks in Industrial IoT environments** from network and MQTT traffic.

The project covers the complete workflow from raw network data preparation to feature engineering, model training and evaluation.

---

## Project Overview

Industrial IoT systems rely heavily on connected devices and communication protocols such as MQTT, making them vulnerable to network attacks.

The objective of this project was to build a machine learning pipeline capable of distinguishing between:

- **Benign network traffic**
- **Malicious / DDoS traffic**

The final processed dataset contained approximately **988,000 network records**.

---

## Workflow

The project follows several stages:

1. Raw PCAP and JSON traffic processing
2. Conversion of network data into structured CSV format
3. Data cleaning and preprocessing
4. Feature engineering
5. Exploratory data analysis
6. Machine learning model training
7. Model comparison
8. Performance evaluation

A Streamlit-based utility was also developed to facilitate the conversion of **PCAP / JSON network data into CSV format**.

## Dataset

The processed dataset contained approximately:

**987,890 observations**

The data was divided into training and testing sets containing both benign and malicious network traffic.

### Main information used

The dataset includes information related to:

- Timestamps
- Source devices
- IP addresses
- MAC addresses
- Applications
- MQTT message information
- MQTT QoS
- MQTT message type
- MQTT topics
- Duplicate messages
- Retained messages

The target variable represents:

```text
0 → Benign traffic
1 → Malicious traffic
```

---

## Feature Engineering

Additional behavioral features were created to improve attack detection.

### Requests per IP

Measures the number of requests generated by each IP address.

This can help identify abnormal request frequencies typically associated with DDoS attacks.

### Duplicate Rate per IP

Measures how frequently duplicate MQTT messages are generated by an IP address.

### Unique Topics per IP

Measures the diversity of MQTT topics accessed by individual IP addresses.

These features help represent the behavior of network devices rather than relying only on individual packets.

## Machine Learning Models

Several supervised machine learning algorithms were evaluated:

- Decision Tree
- K-Nearest Neighbors (KNN)
- Random Forest

The models were compared using classification metrics such as:

- Accuracy
- Precision
- Recall
- F1-score
- Confusion Matrix

---

## Results

The **Decision Tree classifier** achieved the strongest result during the experiments:

| Metric | Result |
|---|---:|
| Accuracy | **97.73%** |
| F1-score | **0.8896** |

The results demonstrate that machine learning models can effectively identify behavioral patterns associated with malicious IIoT network activity.
